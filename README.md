## 下载与同步

所有素材均通过普通 Git 存储，无需安装 Git LFS。克隆仓库即可获得完整文件：

```bash
git clone https://github.com/Qubit-Fernand/pku-jingchu-assets.git
cd pku-jingchu-assets
```

后续使用 `git pull` 更新，修改后使用普通 Git 提交和推送。本仓库为公开仓库，可以直接浏览、下载和克隆。

## 来源与版本

资源由原公共素材目录、活动资料和制作草稿合并，另纳入飞书下载附件。其中29个附件复用项目已有文件，11个从下载目录补入；52处飞书附件和图片引用映射到40份不同内容文件。原始文件按SHA-256核验，整理未改变内容。

飞书附件版现场PPT与协会项目另存的2026年10月9日本地制作稿内容不同；本仓库存放飞书附件版，本地制作稿仍在协会项目中。电子章制作脚本及依赖、完整迁移审计保留在协会项目的工具目录，未纳入素材仓库。

历史ZIP按原样保留，其内部目录属于历史快照。协议签署、聘书颁发、物料印刷和活动采用版本需以实际记录为准。文件来自本地收藏及活动资料，归档不改变第三方素材的权属，也不自动授予转载或商用许可。
